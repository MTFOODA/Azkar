# قائمة لقطات الشاشة لدليل أذكار

هذه القائمة مخصصة لاستكمال الصور عند توفر بيئة عرض آمنة. الصور في هذا المجلد لقطات فعلية للنسخة المحلية؛ بعض المحتوى العام الظاهر فيها بيانات تجريبية.

## اللقطات المتوفرة

- [x] `01-homepage.png` — الصفحة العامة على الهاتف.
- [x] `03-registration.png` — نموذج التسجيل الفارغ كاملًا؛ لم تُدخل بيانات ولم يُرسل.
- [x] `05-azkar.png` — قسم الأذكار في وضع العرض المحلي.
- [x] `09-tasbeeh.png` — بطاقات التسبيح والتنبيه إلى أن العدّاد محلي.

تُنشأ ملفات `*-annotated.png` تلقائيًا من هذه الأصول عند تشغيل `build_guide.py`. تبقى الأصول الخام كما هي.

## لقطات مطلوبة لاستكمال تغطية الدليل

- [ ] شاشة تسجيل الدخول النظيفة، من ملف متصفح جديد لا يحتوي على تعبئة تلقائية أو جلسات مستخدم.
- [ ] قائمة «صفحاتي وروابطي» بحساب عرض مخصص وصفحات تجريبية غير إنتاجية.
- [ ] نموذج «إنشاء صفحة جديدة» مع الحقول والاختيارات، دون إنشاء سجل في حساب حقيقي.
- [ ] «لوحة الصفحة» وقائمة أقسام المحتوى.
- [ ] محرر محتوى تجريبي يوضح «حفظ كمسودة» و«نشر» ومعاينة البطاقة، مع مثال قرآني أو حديثي معتمد.
- [ ] «ترتيب الرئيسية» لإظهار «إضافة بطاقة» وإخفاء المحتوى وإعادة ترتيبه.
- [ ] «المظهر والخطوط» مع المعاينة قبل الحفظ.
- [ ] «إعدادات الصفحة» ومعاينة صفحة تذكار منشورة تجريبيًا.
- [ ] نافذتا «نسخ الرابط» و«مشاركة» دون إرسال الرابط إلى مستلم.
- [ ] صفحة تذكار عامة تجريبية منشورة، بما في ذلك بطاقة التسبيح.

## احتياطات الالتقاط

1. استخدم حسابًا وبيانات عرض مخصصة في بيئة محلية أو تجريبية معتمدة، ولا تنشئ أو تعدّل سجلات إنتاجية من أجل الصور.
2. استخدم ملف متصفح مؤقتًا أو نافذة نظيفة. افحص الحقول بصريًا قبل حفظ أي صورة، ولا تحتفظ بصورة تتضمن بريدًا أو كلمة مرور أو رمزًا أو بيانات شخصية.
3. لا تضغط «إنشاء الحساب» أو «نشر» أو «حذف» إلا في حساب وبيئة عرض مخصصين ومصرح بهما.
4. التقط الشاشة بالحجم الافتراضي. إذا لزم إظهار نموذج كامل، يمكن خفض تكبير المتصفح قليلًا؛ لا تغيّر تخطيط التطبيق أو نصه. قُطعت لقطة التسجيل الحالية بعد خفض التكبير لإظهار النموذج كاملًا.
5. إذا أضيفت أرقام أو أسهم توضيحية، احتفظ بالأصل الخام أيضًا ووضّح أنها طبقة شرح وليست عنصرًا في التطبيق.
