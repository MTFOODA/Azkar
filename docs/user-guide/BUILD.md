# بناء دليل أذكار

## المتطلبات

- Python 3.10 أو أحدث
- Microsoft Edge

## إنشاء النسختين

من هذا المجلد، نفّذ:

```powershell
python -m pip install -r requirements.txt
python build_guide.py
```

ينشئ الأمر `AZKAR_Arabic_User_Guide.docx` القابل للتحرير و`AZKAR_Arabic_User_Guide.pdf` للطباعة. مصدر المحتوى والتصميم هو `AZKAR_Arabic_User_Guide.html`، والصور الفعلية موجودة في `screenshots`.

ينشئ البرنامج نسخًا توضيحية مرقمة من لقطات الشاشة الخام باستخدام Pillow، ثم يضمّنها في الملفين. تبقى اللقطات الأصلية دون تعديل. ويستخدم بناء PDF نسخة Edge مستقلة ومؤقتة، ويطبع الملف المحلي دون تسجيل دخول أو إرسال محتوى إلى خدمة خارجية. يستخدم ملف Word خط Tahoma وإعدادات اتجاه من اليمين إلى اليسار؛ وقد يختار Word خطًا بديلًا إذا لم يتوفر الخط على الجهاز.
